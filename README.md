# Voice Changer Pro

Инструмент для изменения голоса в реальном времени через виртуальный аудио-кабель. Работает во всех программах и играх.

## Возможности

- Настройка виртуального аудио-кабеля (VB-Audio Cable)
- Пресеты голоса (женский, мужской, робот, эхо и др.)
- Интеграция с Voicemeeter для реалистичного изменения тона
- Работает в Discord, CS2, Valorant и других играх

## Установка
git clone https://github.com/thehelpfromthevoid/voice-changer.git
cd voice-changer
pip install colorama
python voicemod/voicemod.py

## Требования

- Windows 10/11
- Python 3.8+
- VB-Audio Virtual Cable (https://vb-audio.com/Cable/)
- Voicemeeter (опционально, для лучшего качества)

## Использование

1. Установите VB-Audio Virtual Cable
2. Запустите скрипт
3. Следуйте инструкциям в меню
4. В игре/программе выберите микрофон CABLE Output
